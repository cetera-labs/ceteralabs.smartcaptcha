# Модуль Bitrix - ceteralabs.smartcaptcha

## Описание
Модуль автоматически заменяет обычную капчу 1С-Битрикс на [Yandex SmartCaptcha](https://yandex.cloud/ru/services/smartcaptcha).

* Поддержка всех форм сайта: регистрация, авторизация, обратная связь
* Поддержка нескольких форм на одной странице
* Поддержка ajax-форм
* Опциональная ленивая инициализация SmartCaptcha
* Отложенная загрузка виджетов в скрытых и находящихся вне видимой области формах

__Если на странице отсутствуют формы с капчей, дополнительные скрипты не будут подключаться!__

### Получение ключей

Способы получения ключей можно узнать в документации по [ссылке](https://yandex.cloud/ru/docs/smartcaptcha/operations/get-keys).

### Настройка модуля

В административном разделе  ( Настройки > Настройки продукта > Настройки модулей > CeteraLabs SmartCaptcha ) вставить полученные ключи.

### Ленивая инициализация

В настройках модуля можно включить ленивую инициализацию SmartCaptcha.

При включённой настройке ресурсы Yandex SmartCaptcha загружаются только тогда, когда форма с CAPTCHA приближается к видимой области страницы и пользователь начинает взаимодействовать с ней.

По умолчанию настройка выключена, поэтому после обновления, установленное ранее на сайте решение продолжает работать в прежнем режиме.

### Дополнительно

В настройках можно изменить подпись и стандартное сообщение об ошибке SmartCaptcha.
